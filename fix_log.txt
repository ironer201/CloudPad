CloudPad - Logical Error Fix Log
Date: 2026-09-21 UTC
Checked by: re-review of backend/, frontend/, cloud/

1. Missing method _write_local (crash on Save)
   Type: broken contract / incomplete refactor
   File: frontend/main_window.py (save_file, save_file_as)
   Symptom: AttributeError on every Save, dirty flag never cleared.
   Fix: added MainWindow._write_local(path) using FileManager.write(),
   with OSError dialog (parent=root), clears edit_modified, updates
   status/title, returns True/False. save_file and save_file_as now
   only update recent/sidebar on True.

2. Missing method refresh_recent (crash on Open/Save)
   Type: stale call after UI removal (see bugFixed.txt #3)
   File: frontend/main_window.py -> frontend/editor_panel.py
   Symptom: AttributeError after successful open/save.
   Fix: implemented EditorPanel.refresh_recent() rebuilding recent_bar
   with up to 3 recent-file buttons (opens via app.open_file).
   Re-enabled call in EditorPanel.__init__.

3. Wrong parent widget on error path
   Type: wrong object reference, only on failure path
   File: frontend/main_window.py open_file exception handler
   Symptom: original file error hidden by AttributeError (self.frame
   does not exist on MainWindow).
   Fix: parent=self.frame -> parent=self.root.

4. Open dialog had no fallback
   Type: inconsistent platform logic / silent failure
   File: frontend/main_window.py open_file
   Symptom: on Windows or without zenity, Open did nothing.
   Fix: added MainWindow._ask_open_path(): try zenity on Linux,
   fall back to filedialog.askopenfilename on cancel/failure or
   non-Linux. Respects zenity cancel vs error.

5. Cloud token-refresh retried with stale token
   Type: stale-state / closure logic error
   File: frontend/main_window.py _cloud / _on_cloud_result refresh
   Symptom: after refresh, retry still sent expired access_token,
   infinite 401 loop.
   Fix: on refresh success rebuild args as
   (new_access_token,) + old_args[1:], update _last_call and resubmit.
   Clear _last_call and reset _tried_refresh on upload/list/download/
   delete success and on final non-retryable error. sign_out now
   resets _tried_refresh=False.

6. Title placeholder wiped real filenames
   Type: unsynced UI state flag
   File: frontend/editor_panel.py set_title / title_var
   Symptom: after open_file/download, focusing title cleared the real
   name. Initial value had leading space " Untitled".
   Fix: initial value "Untitled", set_title() strips, defaults to
   "Untitled", and sets _title_is_placeholder = (text == "Untitled").

7. Shortcuts never fired / incomplete
   Type: incorrect Tk event binding
   File: frontend/main_window.py _build_menu,
         frontend/editor_panel.py title_entry
   Symptom: Ctrl+Shift+S did nothing; Ctrl+A/N/O/S uppercase missed.
   Fix: root binds for Control-N/O plus Control-n/o, Control-s for
   local save, Control-S for cloud save (Shift+s = S in Tk).
   Title entry now binds both Control-a and Control-A.
